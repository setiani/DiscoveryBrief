# DiscoveryBrief demo script — draft

Target duration: 3–4 minutes. Update this script after the independent evaluation and
verify the interface and each displayed claim before recording. No submission or deployment
is implied by this draft.

**0:00–0:30 — Problem.** Explain how a discovery team must prepare from fragmented company
news, user-provided meeting context and RFP text, while avoiding unsupported assumptions.

**0:30–1:10 — Input and research.** Show the local interface, explain that the domain helps
resolve company identity, and distinguish public search context from private user-provided
context. Explain that Tavily performs public Search and Extract, while every model request
passes through Bifrost. Use synthetic data for the demonstration.

**1:10–2:00 — Brief and evidence.** Show the clearly labeled saved synthetic sample or an
approved public/synthetic run. Open a finding and its supporting quote and source; show a
requirement grounded in the user's RFP and a question. Explain the quality label and that
model-assisted verification does not guarantee truth. Never describe replay as a live search.

**2:00–2:35 — Failure or uncertainty.** Demonstrate the identity-clarification outcome or
an empty-evidence result. Explain that uncertainty can prevent a public claim from appearing.
Use a recorded synthetic case if live services are unavailable, and label it accordingly.

**2:35–3:15 — Evaluation and limits.** Show the actual reviewed baseline/candidate results
and denominators only when available. Until review is complete, say that the fixed-evidence
evaluation is pending and give no accuracy claim. Mention that live quality, provider fallback
and release checks remain incomplete as appropriate.

**3:15–3:30 — Close.** Describe the intended outcome: a short meeting-preparation brief with
traceable evidence and explicit uncertainty. Do not claim production readiness or submission.
